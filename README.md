# いしあらい工房

どろだらけの石を水で洗って、光にかざして正体をたしかめる —
のんびり石ころを集める、やさしいドット絵の癒しゲームです。

**オフラインでも遊べる PWA**（ホーム画面に追加できます）。
外部ライブラリ・画像ファイル・音源ファイルは **一切ありません**。
石の絵も、風けいも、音も、ぜんぶその場で作っています。

## あそびかた

| |  |
|---|---|
| 🏞 **ひろう** | 川原や浜辺で、落ちている「どろだんご」をタップして拾います。時間がたつと自然に増えます（アプリを閉じているあいだも）。 |
| 🫧 **あらう** | かごから一つ選んで、指でなでて どろを落とします。「みず」と「ブラシ」を切りかえられます。 |
| ✨ **みがく** | どろが落ちたら、布でこすって つやを出します。つやは図鑑に記録されます。 |
| 🪟 **かざす** | 石をつまんで まどの光に重ねると、中がすけて正体がわかります。 |
| 📖 **ずかん** | 40しゅるいの石を集めます。「洗ったところ」と「光にかざしたところ」の2つの姿が見られます。メモも書けます。 |
| 🪟 **たな** | お気に入りの石や「みつけもの」を、3段の棚にならべて飾れます。 |

失敗はありません。制限時間もありません。好きなだけ ぼんやりしてください。

## 癒しのしかけ

- **ほんとうの時計と天気** — 朝・昼・夕・夜で空の色が変わります。天気（はれ／くもり／あめ／こさめ／きり／ゆき）は15分ごとにゆっくり移り、雨や霧の日はめずらしい石が出やすくなります。冬（12〜2月）だけ雪が降ります。
- **環境音** — 水の音、鳥のさえずり、雨音、夜の虫、洞窟の水滴。すべて WebAudio で合成しています。BGM は五音音階をゆっくりつまびく即興です。
- **工房のねこ** — ときどき遊びに来ます。なでるとゴロゴロ言って、たまに どろだんごを持ってきてくれます。
- **お茶** — きゅうすをタップするとお茶が入り、6分間だけ石が早くたまります。
- **みつけもの** — はっぱ、とりのはね、ながれぼしのかけら…石ではないものも拾えます。棚の飾りに使えます。
- **ひとりごと** — ときどき、ぽつりと言葉が流れます。

## 中身のはなし（技術）

ビルド不要の素の HTML / CSS / ES モジュールです。そのまま静的ホスティングに置けます。

```
index.html          画面の骨組み
styles.css          見た目（ライト／ダーク両対応）
manifest.webmanifest / sw.js    PWA（オフライン対応）
js/
  pixel.js          乱数・ノイズ・色・ピクセル描画の道具箱
  stones.js         40種類の石データ＋手続き的スプライト生成
  state.js          セーブデータ（localStorage）と時間経過
  weather.js        天気と時間帯、空の色
  field.js          石を拾う風けい（6シーン）
  wash.js           どろ落とし＆みがき
  light.js          光にかざす鑑定
  collection.js     図鑑
  shelf.js          飾り棚
  workshop.js       工房の小さな風けい（ねこ・お茶）
  audio.js          環境音・BGM・効果音（すべて合成）
  ui.js             トースト・モーダル・ひとりごと
  main.js           全体の進行と画面切りかえ
```

### 石の絵の作りかた

石は 1つずつ「種（seed）」を持ち、`renderStone(id, seed, size, mode, gloss)` が
その場でドット絵を焼きます。同じ種類でも一つ一つ形と模様がちがいます。

- **かたち** … 角度ごとの半径関数（pebble / round / flat / angular / shard / column / heart）。
  ハートだけは陰関数を光線上で二分探索して求めています。
- **模様** … 26種類のパターン関数（縞・脈・面・金属・苔・化石のうずまき・晶洞の空どう…）。
- **陰影** … 球に近い法線を作って拡散光＋鏡面反射を計算し、**6段階に量子化**してドット絵らしくしています。
- **`mode:'light'`** … 厚みから透過量を求め、ふちほど明るく、まんなかは色が濃く出るようにしています。
  琥珀の虫や晶洞の水晶は、この光モードでだけ はっきり見えます。

### 更新するときの注意

`sw.js` の `CACHE = 'ishiarai-vN'` の番号を **必ず上げてください**。
上げないと、キャッシュから古い画面が出てきます。
